========================================================================
  PdfCraft Enterprise Multi-Printer Edition (الحزمة المحمولة الكاملة)
  المستودع الخاص: https://github.com/ahrrfy/smart-print-
  القناة المصدرية الرسمية: https://github.com/storytold/pdfcraft
========================================================================

1. مكونات الحزمة المحمولة الكاملة (PdfCraft-Portable):
   - pdfcraft.exe        : الواجهة المكتبية الكاملة مع محرك الطباعة المتزامنة لعدة طابعات.
   - pdfcraft-cli.exe    : أداة سطر الأوامر لأتمتة معالجة ملفات PDF.
   - models\             : نماذج التعرف الضوئي على النصوص (OCR) للعمل دون إنترنت (Offline).
   - portable.txt        : مفعّل الوضع المحمول (يحفظ كل الإعدادات والسجلات في PdfCraftData).
   - update_channel.json : إعدادات قناة التحديث الهجينة المرتبطة بمستودع ahrrfy/smart-print-.

2. طريقة التشغيل على حاسوب العمل المرتبط بالطابعات:
   - فك الضغط عن الحزمة أو انسخ مجلد PdfCraft-Portable بالكامل إلى حاسوب العمل، ثم شغّل:
     pdfcraft.exe
   - يحفظ البرنامج كافة إعداداته ومجموعات الطابعات والقوالب داخل مجلد PdfCraftData بجانبه.

3. استقبال التحديثات المستمرة من القناة المصدرية دون تعارض:
   - البرنامج مرتبط تلقائياً بمستودعكم (ahrrfy/smart-print-) وبالقناة المصدرية الرسمية
     (storytold/pdfcraft) عبر قائمة (Help -> Check for updates) أو تلقائياً عند التشغيل:
     * يفحص مسار GitHub Actions (.github/workflows/upstream-sync-release.yml) في مستودعكم
       القناة المصدرية كل 6 ساعات، ويدمج أي إصدار جديد مع تطويرات الطابعات المتعددة ويبني
       الحزمة الكاملة الموثقة بـ SHA-256 وينشرها تلقائياً في Releases.
     * عند الضغط على (Update and Restart)، يقوم البرنامج بتحميل النسخة المدمجة والتحقق من
       بصمة SHA-256 وتحديث البرنامج ذرياً دون فقدان أي إعدادات أو ميزات خاصة.
     * على جهاز التطوير: يمكن أيضاً دمج وبناء أحدث تحديثات المصدر محلياً عبر السكربت:
       powershell -ExecutionPolicy Bypass -File .\scripts\sync-upstream.ps1

4. الطباعة المتزامنة لعدة طابعات بإعدادات موحدة:
   - افتح ملف الـ PDF المطلوب ثم اضغط (Ctrl+P) أو اختر File -> Print.
   - فعّل خيار: [✓] Multi-Printer Cluster Dispatch.
   - حدد الطابعات المطلوبة (أو اضغط Select All، أو احفظها كمجموعة عبر + Save Group).
   - اختر الإعدادات الموحدة مرة واحدة فقط لتُطبَّق فعلياً على جميع الطابعات المحددة:
     * حجم الورق (Paper Size) والملاءمة الذكية للهوامش (Fit / Actual Size / Shrink).
     * الألوان: ملون أو أسود وأبيض نقي (Print in grayscale - K-Only + Driver Monochrome).
     * الوجهين: وجه واحد أو وجهين مع تحديد حافة القلب (Flip on Long Edge / Short Edge).
     * عدد النسخ ونطاق الصفحات والاتجاه (يمكن حفظها كقالب جاهز عبر + Save Preset).
   - اضغط (👁 Preview) أمام أي طابعة لمعاينة هوامشها الفيزيائية الحقيقية قبل الإرسال.
   - اضغط Print لإرسال المهمة بالتوازي لجميع الطابعات المحددة بنفس السرعة والجودة
     ودون أي تعديل أو مساس بملف الـ PDF الأصلي على القرص.

5. التحويل الفوري عند تعطل إحدى الطابعات (One-Click Failover):
   - إذا توقفت إحدى الطابعات أثناء الطباعة (نفاد ورق أو انحشار)، ستظهر نافذة التحويل الذكي
     لتحويل الأوراق المتبقية فقط لطابعة سليمة أخرى بضغطة واحدة ودون تكرار الأوراق المطبوعة.

6. تصدير تقرير التشغيل والأخطاء (Diagnostic Report):
   - من أسفل نافذة الطباعة (قسم Diagnostics & Telemetry):
     * اضغط (📋 Copy Report (MD)) لنسخ التقرير الكامل كجدول Markdown جاهز للإرسال.
     * أو اضغط (💾 Export Diagnostics (JSON)) لحفظ التقرير التفصيلي كملف JSON.

ملاحظة للأجهزة المكتبية القديمة:
- إذا كان كرت الشاشة قديماً ولا يدعم DirectX 12/Vulkan، يمكنك تشغيل البرنامج عبر:
  set PDFCRAFT_RENDERER=gl && pdfcraft.exe
